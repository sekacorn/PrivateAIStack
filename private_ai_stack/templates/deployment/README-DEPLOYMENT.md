# PrivateAIStack Deployment Template

This directory was generated by `privateaistack init`.

## Start

```powershell
docker compose up --build -d
```

## Start With Observability

```powershell
docker compose --profile observability up --build -d
```

## Health

```powershell
privateaistack health --directory .
privateaistack status --directory .
```

The default laptop model is `qwen2.5:3b`. Larger models are optional and are never downloaded automatically.

The Compose file loads `.env.example` and then optional `.env` overrides. Copy `.env.example` to `.env` only when you need local overrides. Do not put production secrets in this template directory.

The API Dockerfile installs `privateaistack[postgres,observability]==0.1.0a1`. Before the package is published, use the repository checkout workflow or override `PRIVATEAISTACK_SPEC` during Docker build.
