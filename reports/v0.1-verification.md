## Remaining Limitations

- Forge native execution currently falls back to direct Ollama after a Forge validation error.
- Policy decisions are testable internally but not audited through a public policy-execution API in v0.1.
- RAG uses PostgreSQL persistence with deterministic local embeddings and exact scoring, not a production ANN retrieval stack.
- Safe-static review does not execute reviewed-project tests or install reviewed-project dependencies.
- Public-sector review remains a product/process responsibility rather than a dedicated runtime feature.
- v0.1.0-alpha is demonstration-grade and needs production hardening, legal/privacy/security review, and organization-specific policy review before operational use.
